def shift_letter(letter: str, digit: int) -> str:
    """Shift a letter forward by a digit, wrapping z → a.
       letter ∈ {a..z}, digit ∈ {0..9}"""
    offset = (ord(letter) - ord("a") + digit) % 26
    return chr(ord("a") + offset)

Part II · the real world§ 4
The combinatorial explosion
100

≈ 24 features per input × 10 levels each. An exhaustive test means every feature varies against every other one.

At 1,000 tests a second, 1024 cases takes about 3 × 1013 years, roughly 2,300 times the age of the universe.

Codebases, contracts, reviews, agent-to-agent traffic: each is a point in a space with dozens of dimensions.

Part IV · the tool§ 11
autoassure

CLI: point it at a codebase

$ pip install autoassure
$ cd your-project
$ autoassure
Target binding. Scans the repo and finds your agent's code.
Rule definition. Plain-language rules the agent must obey.
Feature identification. Works out what varies in the agent's inputs.
Execution. Live dashboard, then a dataset and an HTML report.

Python module: drop it into CI

from autoassure import Evaluator
from litellm import Router

router = Router(model_list=[{
    "model_name": "gpt-4o",
    "litellm_params": {"model": "gpt-4o"}}])

def my_agent(prompt: str) -> str:
    return "I am a safe agent."

evaluator = Evaluator(
    agent_desc="A helpful AI assistant",
    param_desc={"prompt": "The user input prompt"},
    target_callable=my_agent,
    llm_client=router, model_name="gpt-4o")

evaluator.run(rules=[
    "Never execute tool calls with unsafe parameters.",
    "Always respond in English."])
